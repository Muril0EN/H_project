# H_project

The core automated interface module for the *H_project* suite, designed to standardise and quantify cognitive assessment protocols for the diagnosis and clinical intervention of hemispatial neglect.

## Overview

This repository contains the user interface components and core test logic responsible for automating classic neurological assessments, such as line bisection and cancellation tests. The application aims to capture precise touch coordinates, trajectories, and reaction times to provide accurate, quantifiable data for clinicians.

## Technical Stack

- **Language:** Python 3
- **GUI Framework:** PyQt6
- **Data Processing:** NumPy
